Qué son los elementos semánticos

Los elementos semánticos de HTML5 son etiquetas que indican qué función tiene cada parte de una página web. A diferencia de div y span, que son contenedores genéricos sin un significado específico, los elementos semánticos describen el contenido que contienen. La etiqueta div se utiliza para agrupar bloques de contenido y span para agrupar texto u otros elementos en línea, por ejemplo, para aplicar estilos.

header: representa la cabecera de una página o sección y suele contener un título o una introducción.

nav: contiene los enlaces de navegación que permiten desplazarse por la página o acceder a otras páginas.

main: contiene el contenido principal de la página y solo debe haber uno por documento.

section: agrupa contenido relacionado con un mismo tema y normalmente tiene un encabezado.

article: representa contenido independiente que puede entenderse por sí mismo, como una noticia o un comentario.

aside: contiene información complementaria relacionada con el contenido principal, como una curiosidad.

footer: representa el pie de una página o sección y puede incluir información adicional o de contacto.

address: contiene información de contacto del autor o responsable de la página o del artículo.

¿Sabías que…?

Utilizar elementos semánticos tiene tres ventajas principales: mejora la accesibilidad para las personas que utilizan lectores de pantalla, facilita la comprensión y el mantenimiento del código y ayuda a los buscadores a interpretar mejor el contenido.
